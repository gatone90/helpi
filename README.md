# HELPi Webfront

Hola, este es el frontend web de HELPi, una plataforma que conecta a personas que pueden donar con personas y organizaciones que necesitan apoyo.

## Requirements

- Node.js 20.9 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The app uses Next.js App Router, React, TypeScript, and plain CSS. The current home page is an initial responsive product landing page in Argentine Spanish.
