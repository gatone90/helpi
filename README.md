# HELPi Webfront

HELPi es una plataforma que conecta a personas que pueden donar con personas y organizaciones que necesitan apoyo.

## Ejecutar localmente

### Requisitos

- Node.js 20.9 o superior
- npm

### Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

El frontend usa Next.js App Router, React, TypeScript y CSS. La página principal actual es una landing page inicial y adaptable, en español rioplatense.

## Identidad de marca

La marca busca transmitir **cercanía, confianza, alegría y conexión**. Ayudar debe sentirse fácil, humano y accesible; la comunidad es la protagonista y HELPi facilita el encuentro entre necesidades y oportunidades. La identidad apunta a ser moderna, inclusiva y emocionalmente cercana, con una estética tecnológica.

### Helpi, la mascota

El nombre correcto es **Helpi**, con *i* latina. Es una criatura amigable con forma de corazón, cálida, cercana y abrazable, con formas suaves y una expresión acogedora. Su personalidad es curiosa, optimista, empática y resolutiva. No juzga ni se presenta como héroe o salvador: ayuda a que las personas se encuentren.

### Dirección visual

- **Color principal:** coral o rojo suave, sin saturación excesiva.
- **Color secundario:** celeste.
- **Estilo:** formas redondeadas e ilustraciones simples, adaptable a la aplicación, stickers, redes sociales y presentaciones.
- **Tipografía exploratoria:** Nunito o Poppins.

La paleta y la tipografía son una dirección inicial; sus valores y especificaciones finales todavía están pendientes.

### Tono dentro de la aplicación

- **Al publicar una donación:** «¡Qué bueno que tengas algo para compartir! Te ayudo a encontrar quién lo necesita.»
- **Al buscar algo necesario:** «Contame qué necesitás y busquemos juntos quién puede ayudarte.»
- **Al producirse una coincidencia:** «¡Encontramos una coincidencia! Una ayuda está más cerca de llegar.»
